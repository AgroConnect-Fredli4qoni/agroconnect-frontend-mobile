# Repositori: agroconnect-frontend-mobile
## Aplikasi Mobile Petani Lapangan (React Native)
**Skema Sertifikasi**: BNSP Full-Stack Developer | **Kandidat**: Fredli Fourqoni

---

### Deskripsi
Aplikasi mobile berbasis **React Native** yang dirancang untuk operasional praktis petani langsung di kebun atau lahan pertanian.

### Fitur Utama:
1. **Pemantauan Cuaca Lapangan**: Notifikasi peringatan cuaca BMKG dan status rekomendasi tani harian.
2. **Katalog & Stok Lapangan**: Cek dan perbarui jumlah stok hasil panen secara cepat.
3. **Pemberitahuan Pesanan Masuk**: Melihat pesanan yang diterima dari pembeli komoditas.

### Menjalankan Aplikasi
```bash
npm install
npm start
```
